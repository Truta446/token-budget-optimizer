# Frequently asked questions

**Can I change my workspace region?**
Enterprise workspaces can choose the EU (Frankfurt) or US (Virginia) region at
creation time. The region cannot be changed later.

**Do you offer a free plan?**
Yes. Starter is free for up to 3 projects and 10,000 API requests per month.

**How do I rotate an API key?**
Create a new key, deploy it to your services, then revoke the old key. Revoked
keys stop working within 60 seconds.

**Is there an on-premises version?**
No. Acme Cloud is offered as a managed service only.
